================================================================================
                EASY TO EXCEL CLEAR — QUICK COMMANDS
================================================================================

PREREQUISITES:
✓ Node.js 18+ installed
✓ Claude API key from console.anthropic.com
✓ Project extracted to a folder

================================================================================
                              SETUP (First Time)
================================================================================

STEP 1: CREATE BACKEND .env FILE
────────────────────────────────────────────────────────────────────────────
Location: easy-to-excel-clear/backend/.env

Content:
NODE_ENV=development
PORT=5000
CLAUDE_API_KEY=sk-ant-PASTE_YOUR_API_KEY_HERE
AI_MODEL=claude-sonnet-5-20250929

STEP 2: CREATE FRONTEND .env.local FILE
────────────────────────────────────────────────────────────────────────────
Location: easy-to-excel-clear/frontend/.env.local

Content:
VITE_API_URL=http://localhost:5000

================================================================================
                          RUNNING THE APPLICATION
================================================================================

TERMINAL 1 - START BACKEND:
────────────────────────────────────────────────────────────────────────────
cd backend
npm install
npm run dev

Expected output:
✓ Server running on http://localhost:5000
✓ API health check: http://localhost:5000/api/health
✓ Keep this terminal open

TERMINAL 2 - START FRONTEND (New terminal/window):
────────────────────────────────────────────────────────────────────────────
cd frontend
npm install
npm run dev

Expected output:
✓ Server running on http://localhost:5173
✓ Open http://localhost:5173 in your browser

OPEN APPLICATION:
────────────────────────────────────────────────────────────────────────────
1. Open web browser
2. Go to: http://localhost:5173
3. Start converting documents!

================================================================================
                              BASIC WORKFLOW
================================================================================

1. Click "Upload Your File"
2. Select a PDF, JPG, PNG (max 10 MB)
3. Wait for extraction (~15-30 seconds)
4. Review extracted data
5. Edit if needed (add/delete rows, rename columns)
6. Click "Download Excel File"
7. Open in Excel or Google Sheets

BUILD BACKEND:

cd backend

================================================================================
                        TROUBLESHOOTING COMMANDS
================================================================================

BACKEND NOT STARTING:
────────────────────────────────────────────────────────────────────────────
# Check Node version
node --version

# Clear and reinstall
cd backend
rmdir /s node_modules
npm cache clean --force
npm install
npm run dev

FRONTEND NOT LOADING:
────────────────────────────────────────────────────────────────────────────
# Check if port 5173 is free
netstat -ano | findstr :5173

# Reinstall
cd frontend
npm cache clean --force
npm install
npm run dev

API CONNECTION ERROR:
────────────────────────────────────────────────────────────────────────────
# Verify backend is running
curl http://localhost:5000/api/health

# Check frontend .env.local has correct URL
cat frontend/.env.local

CLAUDE API ERROR:
────────────────────────────────────────────────────────────────────────────
# Verify API key in backend/.env
cat backend/.env

# No spaces around key!
# Restart backend after changes

CLEAN UP TEMPORARY FILES:
────────────────────────────────────────────────────────────────────────────
cd backend
rmdir /s uploads
